Download the universal macOS `.dmg` below (Apple Silicon and Intel). Open it,
drag Branchlight to Applications, then launch it from Applications.

Branchlight uses your installed Git, SSH configuration, and credential helpers.
Git must already be installed and configured. It is not bundled with the app.

This release is Developer ID signed and notarized. `SHA256SUMS.txt` contains
the installer checksum. Updates are installed manually by downloading a newer DMG.
