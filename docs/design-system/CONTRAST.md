# Palette contrast evidence

Generated by `bun docs/design-system/build.mjs` from `themes.json`.

These are proposed opaque sRGB token pairs, not a product accessibility certification.
Ratios use WCAG relative luminance, with unrounded values compared against thresholds.
Normal text requires 4.5:1; controls, focus rings, and graph lanes require 3:1
against the declared adjacent surfaces. Decorative separators and disabled controls
are excluded. No claim is made about contrast between graph lanes, color-vision
distinguishability, native dialogs, transparency, or operating-system rendering.
